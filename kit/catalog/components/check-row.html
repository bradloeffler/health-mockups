Check row

A checklist row: checkbox · label · optional trailing number. Done rows dim to --c-faint. Stack rows inside a flush card with .k-hairline between them.

Sizes

Only the vertical padding changes; the checkbox, label size and gap stay the same. Roomy (16px) for full-width lists with room to spare, default (12px), snug (8px; 34px rows with the small checkbox, used by Home's Meals and Habits), and compact (4px, 30px rows) for the tightest lists.
